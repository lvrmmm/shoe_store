# Shoe Store - Магазин обуви

[![Maintainability](https://qlty.sh/gh/lvrmmm/projects/shoe_store/maintainability.svg)](https://qlty.sh/gh/lvrmmm/projects/shoe_store)

## О проекте

Приложение для управления магазином обуви. Разработано в рамках практического задания по дисциплине "МРПО". Система позволяет управлять товарами и заказами с разграничением прав доступа для различных ролей пользователей.

### Функциональные возможности

#### Для всех пользователей:
- Просмотр каталога товаров
- Авторизация с проверкой логина и пароля
- Вход в режиме "Гость"

#### Для авторизованного клиента:
- Просмотр каталога товаров

#### Для менеджера:
- Просмотр товаров с возможностью поиска, фильтрации и сортировки
- Управление заказами

#### Для администратора:
- Полный CRUD для товаров (создание, чтение, обновление, удаление)
- Полный CRUD для заказов
- Управление изображениями товаров
- Поиск, фильтрация и сортировка товаров и заказов

## Технологический стек

## Установка и запуск

### Требования
- Java 17 или выше
- PostgreSQL 14 или выше
- Maven 3.8+

### Настройка базы данных

1. Создайте базу данных PostgreSQL:
```sql
CREATE DATABASE shoe_store;
```

2. Выполните скрипты инициализации базы данных из папки Модуль 1:

- Создание_таблиц_БД.sql - создание структуры БД
- Данные_для_заполнения_таблиц.sql - заполнение тестовыми данными
- Проверка_заполнения_БД_данными.sql - проверка заполнения

3. Настройте подключение к БД в src/main/resources/application.properties:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/shoe_store
spring.datasource.username=postgres
spring.datasource.password=your_password
spring.datasource.driver-class-name=org.postgresql.Driver
spring.jpa.hibernate.ddl-auto=validate
```

### Сборка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd shoe_store

# Сборка проекта
mvn clean package

# Запуск приложения
mvn spring-boot:run
```

## Особенности реализации

### Визуальное оформление

- Единый стиль интерфейса согласно руководству по стилю
- Иконка приложения и логотип компании
- Подсветка товаров в зависимости от скидки и наличия на складе:
- Скидка > 15%: зеленый фон (#2E8B57)
- Отсутствие товара: голубая подсветка строки

### Функционал товаров

- Поиск в реальном времени по всем текстовым полям
- Фильтрация по поставщику
- Сортировка по количеству (возрастание/убывание)
- Добавление/редактирование товаров только для администратора
- Загрузка изображений товаров с ограничением размера 300×200 пикселей
- Удаление товара только если он не присутствует в заказах

### Функционал заказов

- Просмотр списка заказов для менеджера и администратора
- Добавление/редактирование/удаление заказов только для администратора
- Автоматическая генерация кода получения заказа
- Валидация дат (дата выдачи не может быть раньше даты заказа)

### Безопасность

- Проверка прав доступа перед каждым действием
- Защита от открытия множества окон редактирования
- Информативные сообщения об ошибках
- Подтверждение необратимых действий
